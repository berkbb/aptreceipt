# User Rejected Specs & Anti-Feature Redlines

This document tracks rejected ideas and anti-patterns that must not be introduced into the project.

- **Cloud/Remote Backend Dependency**: No mandatory external servers, Firebase, AWS, or SaaS accounts. All operations must run strictly locally on macOS.
- **Aggressive Subscriptions/Paywalls**: No artificial limits on receipt count or apartment size.
- **Telemetry & Tracking**: No third-party analytics libraries.
